# Lesson 01 — Introduction to Dart

## Learning Objectives

By the end of this lesson, you should be able to:

- Explain why Flutter uses Dart.
- Understand the difference between a programming language and a framework.

---

## What is Dart?

Dart is a general-purpose programming language developed by Google.

It is designed to build fast, reliable and maintainable applications across multiple platforms.

Although Dart can be used independently to build command-line applications, servers and web applications, it is most widely known as the language used by Flutter.

---

## What is Flutter?

Flutter is Google's UI framework for building beautiful, natively compiled applications from a single codebase.

Flutter provides everything needed to build user interfaces such as:

- Buttons
- Text
- Images
- Animations
- Navigation
- Layouts

Flutter is **not** a programming language.

Instead, it is a framework written using Dart.

---

## Dart vs Flutter

| Dart | Flutter |
|------|----------|
| Programming Language | UI Framework |
| Defines syntax and language rules | Provides UI components and tools |
| Can exist without Flutter | Depends on a programming language |
| Compiles source code | Builds applications using Dart |

---

## Why Flutter Uses Dart

Flutter needs a programming language to describe application behaviour.

Google chose Dart because it offers:

- Fast compilation
- Excellent developer experience
- Strong typing
- Null safety
- High performance
- Hot Reload support

Together, Flutter and Dart allow developers to build applications for Android, iOS, Web and Desktop from a single codebase.

---

## Engineering Takeaway

A programming language tells the computer **what to do**.

A framework provides tools that make solving common problems easier.

Flutter builds user interfaces.

Dart provides the language that makes those interfaces behave correctly.
