# Challenge 07: Null Safety

## Objective

Practice Dart's null safety features using a simple user profile scenario.

You will work with:

- Nullable variables
- `?.`
- `??`
- `??=`
- Null checks
- Nullable lists
- Nullable function parameters
- Return values

## Tasks

**Task 1:** Create `getDisplayName()` and return the username or `"Guest"`.

**Task 2:** Create `getEmailLength()` and return the email length or `0`.

**Task 3:** Create `setDefaultPhone()` and assign `"Not provided"` when the phone is null.

**Task 4:** Create `displayPhone()` and handle a missing phone number.

**Task 5:** Create `findNotification()` that accepts a nullable notification and provides `"No notification"` when needed.

**Task 6:** Create `displayNotifications()` and ignore null notifications without using `!`.

**Task 7:** Create `getUserSummary()` and display sensible fallback values for missing user information.

**Task 8:** Create `getSafeUsername()` that accepts a nullable username and returns `"Anonymous"` when necessary.

## Run

From the challenge directory:

```bash
dart run
```

Try to complete the challenge before checking the solution.
