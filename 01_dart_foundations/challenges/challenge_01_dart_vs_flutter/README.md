# Challenge 01 — Your First Dart Program

## Objective

Become familiar with creating and running a simple Dart console application while reinforcing the difference between Dart and Flutter.

---

## Scenario

You have just joined a mobile engineering team.

As part of your onboarding, your team lead asks you to create a simple Dart program that introduces Dart and Flutter.

The goal is not to build a Flutter app.

The goal is to understand that Dart can run independently of Flutter.

---

## Requirements

Create a Dart console application that prints the following information:

- Your name
- What Dart is
- What Flutter is
- One key difference between Dart and Flutter
- A sentence explaining why Flutter uses Dart

---

## Expected Learning

After completing this challenge, you should understand that:

- Dart is a programming language.
- Flutter is a UI framework.
- Dart can run without Flutter.
- Flutter relies on Dart to build applications.

---

## Stretch Goal

Modify the program to print each piece of information using a separate function.

> You'll revisit this challenge after completing the Functions lesson.
