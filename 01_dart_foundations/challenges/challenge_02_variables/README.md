# Challenge 02 — Banking System Variables

## Objective

Practice creating variables by modelling a simple bank account.

---

## Scenario

A bank wants to build a console application that stores customer information.

Your task is to create variables that represent a customer's bank account and display the information in the console.

---

## Requirements

Create variables for:

- Account holder name
- Account number
- Account balance
- Account type
- Active status

Print all the values to the console in a readable format.

---

## Expected Learning

After completing this challenge, you should understand:

- How to declare variables.
- How to assign values.
- How to choose appropriate data types.
- Why meaningful variable names improve readability.

---
